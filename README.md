# Baker's Guns & Ammo

Responsive informational storefront website prototype for Baker's Auto & Tire LLC – Guns & Ammo in Andrews, NC.

This site uses photographs provided for the project. Business details, permissions, contact information, and services require store-owner verification before public promotion.

## Deploy

Static site rooted at `/`. GitHub Actions deploys `index.html`, `styles.css`, `script.js`, and `assets/` to GitHub Pages.

No online firearm purchase, checkout, or inventory functionality is included.
